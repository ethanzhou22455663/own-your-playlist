课程笔记：连接保存功能与前端选择

2026-08-25 · Own Your Playlist 项目

本节课目标

让 Electron 桌面应用能够：

  1. 通过 IPC 把用户在网页端修改的歌曲标签写回 MP3 文件。
  2. 在前端用勾选框选择歌曲，并打开编辑面板进行编辑。

1. 新增 save-tags IPC 通道

数据流

网页 JS → preload.cjs → electron-main.ts → writer.ts → MP3 文件

preload.cjs：暴露安全接口

contextBridge.exposeInMainWorld('electronAPI', {
  scanMusic: (folderPath) => ipcRenderer.invoke('scan-music', folderPath),
  saveTags: (filePath, tags) => ipcRenderer.invoke('save-tags', filePath, tags),
});

electron-main.ts：注册处理器

ipcMain.handle('save-tags', async (_event, filePath, tags) => {
  if (typeof filePath !== 'string') {
    throw new Error('filePath 必须是字符串');
  }
  if (typeof tags !== 'object' || tags === null) {
    throw new Error('tags 必须是对象');
  }

  const raw = tags as Record<string, unknown>;
  const update: TagUpdate = {};

  if (typeof raw.title === 'string') update.title = raw.title;
  if (typeof raw.artist === 'string') update.artist = raw.artist;
  if (typeof raw.album === 'string') update.album = raw.album;
  if (typeof raw.trackNumber === 'string') update.trackNumber = raw.trackNumber;
  if (typeof raw.genre === 'string') update.genre = raw.genre;
  if (typeof raw.composer === 'string') update.composer = raw.composer;

  await writeTags(filePath, update);
  return { success: true };
});
要点：IPC 收到的数据类型是 unknown，主进程要先检查再使用，不能直接信任网页传来的内容。

2. 给歌曲生成稳定 ID

之前用 track.filePath 当 DOM 的 data-id，但 Windows 路径里有 \，会导致 CSS 选择器匹配失败。

解决方案：在 scanner.ts 里给每首歌生成 UUID。

import { randomUUID } from 'node:crypto';

export interface MusicFile {
  id: string;        // 新增
  filePath: string;
  title: string;
  // ...
}

// 创建 track 时
tracks.push({
  id: randomUUID(),
  filePath,
  title: metadata.common.title ?? entry.name,
  // ...
});
结果：前端统一用 track.id 来识别歌曲，不再依赖文件路径。

3. 前端选择逻辑

核心数据结构

let selectedTracks = [];  // 存放被选中的 MusicFile 对象

切换选中状态

function toggleSelection(track) {
  const index = selectedTracks.findIndex(t => t.id === track.id);

  if (index >= 0) {
    selectedTracks.splice(index, 1);  // 取消选中
  } else {
    selectedTracks.push(track);        // 选中
  }

  renderTracks();  // 整体重绘
}

渲染时根据选中状态生成 checkbox

const isSelected = selectedTracks.some(t => t.id === track.id);

tr.innerHTML = `
  <td><div class="checkbox ${isSelected ? 'checked' : ''}">${isSelected ? '✓' : ''}</div></td>
  ...
`;
注意：事件监听器要绑在 checkbox 上，并调用 e.stopPropagation()，防止触发整行点击。

4. 渲染策略：整体重绘

策略 优点 缺点
局部更新 性能高 逻辑分散，不同操作要维护多套规则
整体重绘 逻辑统一，代码简单 数据量大时性能差

本项目歌曲数量不多，选择整体重绘。勾选、搜索、拖拽排序、保存后刷新都可以统一走 renderTracks()。

  if (selectedTracks.length === 0) return;

6. 关键概念复习

函数作用域

函数能访问哪些变量，由它在哪里定义决定，不是由在哪里调用决定。

function outer() {
  const x = 1;

  function inner() {
    console.log(x);  // ✅ 可以访问，因为 inner 在 outer 里定义
  }

  inner();
}

function another() {
  inner();  // ❌ 这里调用 inner，inner 也访问不到 another 里的变量
}

some / findIndex / splice

  • some()：检查数组里有没有满足条件的元素，返回 true / false。
  • findIndex()：找到满足条件的元素的索引，找不到返回 -1。
  • splice(index, 1)：从数组的 index 位置删除 1 个元素。

模板字符串与三元运算符

const isSelected = true;

const className = isSelected ? 'checked' : '';  // 'checked'
const icon = isSelected ? '✓' : '';              // '✓'

const html = `<div class="checkbox ${className}">${icon}</div>`;
// 结果：<div class="checkbox checked">✓</div>
