Concepts touched

  • Electron bridge file: a .cjs file that registers the tsx loader so Electron can run TypeScript code.
  • BrowserWindow: the Electron API that creates a desktop window.
  • loadFile: how the main process tells a window which local HTML page to display.
  • URL vs path: a URL is a universal resource address; a path is a local file-system address. On Windows, converting between them needs care.
  • Main process: the Node.js process that starts first and can access files.
  • Renderer process: the web page inside the window; it cannot access files directly.
  • IPC (Inter-Process Communication): the message-passing system between main and renderer processes.
  • preload script: a small script loaded before the page, used to safely expose main-process capabilities to the renderer.
  • contextBridge: an Electron API that creates a safe, limited bridge between Node/Electron and the web page.
  • ipcRenderer: the renderer-side tool for sending IPC messages.
  • ipcMain: the main-process tool for receiving IPC messages.
  • require vs import: two ways to load modules; require is used in CommonJS (.cjs), import is used in ES modules/TypeScript.
  • Destructuring: the const { a, b } = object syntax that pulls properties out of an object into standalone variables.
