Lesson 2026-08-23: Electron GUI Introduction

Goal of the lesson

Start building a desktop GUI for the music editor so the user can select songs and batch-edit tags without using the command line.

Key decision: from web server to Electron

We first considered a browser + local HTTP server design. The browser would talk to a hidden Node.js server that reads and writes MP3 files.

This was rejected because it feels like a web service, requires a port, and does not match the idea of a local downloadable application.

We chose Electron instead:

  • One downloadable app.
  • The UI is still a web page, so we keep using HTML, CSS, and TypeScript.
  • The app can read and write local files through Node.js.
  • No separate server process, no network required.

Concepts touched

  • Electron: a tool that packages a web page into a desktop application.
  • Main process: the Node.js part that starts first and can access files.
  • Renderer process: the web page the user sees inside the window.
  • npm scripts: shortcuts in package.json that run commands.
  • devDependencies: libraries needed during development but not in the final app.
  • npm mirror: an alternative download server used when the default server is slow or blocked.
  • CommonJS (.cjs): an older way Node.js loads files, using require.
  • ES modules: the modern way JavaScript loads files, using import.
  • tsx: a tool that lets Node.js run TypeScript files directly.

Teaching feedback recorded

During this lesson the student gave important feedback about teaching style:

  • Do not dump full scripts or many files at once.
  • Explain the thinking and concepts before showing code.
  • Every new term must be defined immediately.
  • Comments must explain every line and every symbol.
  • Use plain language, one concept at a time.
  • Build from the smallest working version and add one feature at a time.

These rules were added to the teach-while-coding skill file.

Where the next lesson starts

Begin with the smallest possible Electron app:

  1. Create src/electron-main.cjs, the two-line bridge that loads TypeScript.
  2. Create the simplest src/main.ts that opens an empty window.
  3. Run npm run electron and confirm a window appears.
  4. Only then add index.html and load it into the window.

Each step must be tiny, fully explained, and confirmed before moving on.
